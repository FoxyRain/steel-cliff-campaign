# 🏰 Стальной Утёс — Сайт кампании

Интерактивный сайт для проведения кампании D&D 5e в городе Стальной Утёс.
Размещён на GitHub Pages, все данные редактируются через JSON-файлы.

## 🌐 Как открыть сайт

После публикации: `https://ВАШ_НИК.github.io/steel-cliff-campaign/`

## ✏️ Как редактировать контент

1. Откройте нужный файл в папке `/data/` (city.json, factions.json, quests.json и т. д.)
2. Нажмите значок карандаша в GitHub
3. Внесите изменения
4. Нажмите "Commit changes"
5. Сайт обновится в течение 1–2 минут

## 🚀 Как развернуть на GitHub Pages

1. Создайте репозиторий `steel-cliff-campaign`
2. Загрузите все файлы
3. Зайдите в `Settings` → `Pages`
4. Выберите ветку `main`, папку `/root`
5. Сохраните — сайт станет доступен по ссылке

## 🗺️ Разделы

- **Город** — районы, локации, экономика
- **Фракции** — стража, гильдии, бордель
- **Квесты** — основной и побочные
- **NPC** — жители и их тайны
- **Бестиарий** — монстры и союзники
- **Карты** — планы локаций
